# P3 Minishell

Durante el desarrollo de esta práctica realizarás un minishell con el objetivo de:

- Usar llamadas al sistema y funciones de las bibliotecas estándar de C y sistemas POSIX.
- Gestionar errores.
- Crear y gestionar procesos.
- Cambiar la imagen en ejecución de un proceso.
- Redirigir a un fichero la entrada y/o la salida estándar de un proceso.
- Ejecutar (y gestionar) procesos en segundo plano.
